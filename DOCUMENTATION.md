## 1. Обзор проекта

**INKFORGE** — одностраничный сайт тату-студии премиум-класса, разработанный на React + TypeScript с использованием Vite и shadcn/ui. Сайт представляет собой современный, тёмный, привлекательный лендинг с 16 секциями, охватывающими все аспекты бизнеса тату-студии.

### Ключевые особенности

- **16 секций** главной страницы, каждая реализована отдельным компонентом
- **Тёмная цветовая тема** в красно-чёрных тонах, идеально подходящая для тату-салона
- **90+ изображений** татуировок, студии, оборудования и мастеров
- **Онлайн-бронирование** с календарём и слотами времени
- **Форма обратной связи** с валидацией
- **Адаптивный дизайн** для всех устройств (мобильные, планшеты, десктопы)
- **Микро-анимации** и hover-эффекты для улучшения UX
- **Максимальное использование shadcn/ui** компонентов

## 4. Дизайн-система

### Цветовая палитра

Сайт использует тёмную тему, специально разработанную для тату-студии. Основные цвета — глубокий чёрный фон с акцентным красным (цвет крови/чернил).

| Переменная | Значение (HSL) | Назначение |
|------------|----------------|------------|
| `--background` | `0 0% 7%` | Основной фон (почти чёрный) |
| `--foreground` | `30 15% 95%` | Основной текст (тёплый белый) |
| `--card` | `0 0% 10%` | Фон карточек |
| `--popover` | `0 0% 10%` | Фон попапов |
| `--primary` | `0 85% 55%` | Акцентный красный |
| `--primary-foreground` | `0 0% 100%` | Текст на красном |
| `--secondary` | `0 0% 14%` | Вторичный фон |
| `--muted` | `0 0% 14%` | Приглушённый фон |
| `--muted-foreground` | `0 0% 55%` | Приглушённый текст |
| `--accent` | `0 0% 16%` | Акцентный фон |
| `--destructive` | `0 72% 45%` | Ошибки/удаление |
| `--border` | `0 0% 18%` | Границы |
| `--ring` | `0 85% 55%` | Кольцо фокуса |

### Кастомные утилитарные классы

- `.bg-grid` — сетка из тонких линий для фона секций
- `.bg-radial-fade` — радиальный градиент для плавного затухания фона
- `.glow-red` — красное свечение для ключевых кнопок
- `.text-glow` — свечение текста для заголовков
- `.text-balance` — балансировка строк текста
- `.animate-fade-in-up` — анимация появления снизу
- `.animate-shimmer` — эффект мерцания для скелетонов

### Типографика

- Шрифт: **Inter** (system-ui fallback)
- Заголовки: font-black (900), 4xl–7xl
- Основной текст: text-muted-foreground, leading-relaxed
- Межстрочный интервал: 150% для основного текста, 105% для заголовков

### Отступы

Используется 8px-система (Tailwind default). Секции имеют вертикальный padding `py-24` (96px). Контейнер — `container mx-auto px-4`.

## 11. Адаптивность

Сайт полностью адаптивен с breakpoints Tailwind:

| Breakpoint | Ширина | Изменения |
|------------|--------|-----------|
| Mobile (default) | < 640px | 1 колонка, Sheet-меню, скрытые изображения Hero |
| sm | ≥ 640px | 2 колонки в сетках |
| md | ≥ 768px | 3 колонки, видна карусель навигация |
| lg | ≥ 1024px | 4+ колонки, полная навигация, Hero-изображения |
| xl | ≥ 1280px | 4 колонки в галерее |

### Мобильное меню

При ширине экрана < 1024px навигация скрывается и заменяется кнопкой-гамбургером, открывающей Sheet (выезжающая панель справа) со всем содержимым навигации.

## 12. Бронирование

Секция бронирования (`Booking.tsx`) включает:

1. **Календарь** — выбор даты (прошедшие дни отключены)
2. **Слоты времени** — 11 вариантов с 11:00 до 21:00 (активны только после выбора даты)
3. **Выбор мастера** — выпадающий список с 4 мастерами
4. **Контактные поля** — имя, телефон, описание идеи
5. **Прогресс-бар** — отображает готовность заявки (0% → 100%)
6. **Toast-уведомление** — подтверждение при отправке или ошибка при незаполненных полях

### Логика

- Прогресс обновляется при заполнении каждого ключевого поля (дата, время, мастер)
- Кнопка "Отправить заявку" проверяет заполнение обязательных полей
- При успехе показывается toast с датой и временем записи
- При ошибке показывается destructive toast с инструкцией

## 13. Форма обратной связи

Секция контактов (`Contacts.tsx`) включает:

1. **4 контакт-карточки** — телефон, email, адрес, часы работы
2. **Карта-плашка** — изображение студии с адресом и кнопкой маршрута
3. **Соцсети** — 3 кнопки (Instagram, Telegram, ВКонтакте)
4. **Форма** — имя, телефон, email, сообщение, чекбокс согласия
5. **Toast** — подтверждение отправки

### Валидация

- Имя, телефон и сообщение — обязательные поля (HTML `required`)
- Чекбокс согласия на обработку данных — обязателен
- При отправке показывается toast "Сообщение отправлено!"
